# Was bei @gruenenrw wirklich zählt – Reel-Analyse

Analyse aller Instagram-Reels von **@gruenenrw** vom 21.10.2025 bis 20.10.2026 (147 Reels), mit einem Blick auf TikTok. Inhalte: Formate, Gesichter des Kanals, Viral-Hits und Flops, Zielgruppen, die neuen Creator Torben und Julian, Empfehlungen für 2027.

- **Animierte Präsentation:** `index.html`, über GitHub Pages direkt im Browser
- **PDF (16:9):** `Gruene-NRW_Reel-Analyse_2026-10-21.pdf`
- **Tabelle:** `reels.csv`, eine Zeile je Reel mit Datum, Plays, Likes, Kommentaren, Person, Format, Thema und Transkript

## Bedienung der Präsentation

| Taste | Funktion |
|---|---|
| → / Leertaste / Klick | weiter |
| ← | zurück |
| F | Vollbild |

| R | Animation der Folie wiederholen |
| B | Schwarzbild |

Auf dem Handy wischen. `#12` am Ende der Adresse öffnet Folie 12.

## Datenbasis

Öffentliche Kennzahlen über Apify, Stand 20.10.2026 (Instagram) und 21.10.2026 (TikTok). Transkripte entstanden lokal mit whisper.cpp. Follower-Verlauf, Demografie, Shares und Saves auf Instagram sind öffentlich nicht abrufbar; Zielgruppen sind deshalb aus Themen und Kommentaren abgeleitet. Vorschaubilder und Standbilder stammen aus den analysierten Reels und gehören den jeweiligen Accounts.
